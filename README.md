# h100-vllm

- `vllm-cu129`: cu129 Python environment without installing CUDA Toolkit or cuDNN.
- `vllm-cu129-ubuntu2604`: cu129 environment for Ubuntu 26.04 with CUDA Toolkit 12.9.1 installed from NVIDIA's toolkit-only runfile and wheel-packaged cuDNN.
- `vllm-cu130`: cu130 Python environment without installing CUDA Toolkit or cuDNN.
- `vllm-cu130-ubuntu2604`: cu130 environment for Ubuntu 26.04 with CUDA Toolkit 13.0.2 installed from NVIDIA's toolkit-only runfile and wheel-packaged runtime libraries.
- `vllm-cu129-nvcc-cudnn`: cu129 environment with CUDA Toolkit and cuDNN installation.
- `vllm-cu130-nvcc-cudnn`: cu130 environment with CUDA Toolkit and cuDNN installation.
